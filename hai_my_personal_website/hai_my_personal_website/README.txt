WEBSITE CÁ NHÂN - HẢI MY

Cấu trúc:
- index.html       : Trang chủ / giới thiệu bản thân
- hobbies.html     : Trang sở thích
- contact.html     : Trang liên hệ
- style.css        : Định dạng giao diện dùng chung
- assets/panda.jpg : Ảnh gấu trúc bạn đã đính kèm

Cách xem:
1. Giải nén file ZIP.
2. Mở thư mục hai_my_personal_website.
3. Nhấp đúp vào index.html để mở website trên trình duyệt.

Đây là website tĩnh HTML/CSS, không cần cài đặt máy chủ.
Bạn có thể chỉnh nội dung trong các file HTML và màu sắc trong style.css.
